## What's Changed

### Better everyday text prompts

- Improved prompt enhancement for Claude, ChatGPT, Gemini, and generic AI assistants.
- Enhancements now preserve supplied facts, uncertainty, exact wording, counts, limits, tone, audience, and multi-turn interaction boundaries.
- Rewriting and translation requests keep source text intact instead of altering it while constructing the prompt.
- Summarization, research, comparison, decision-support, teaching, brainstorming, and creative requests now receive task-appropriate guidance without invented context or arbitrary formats.
- Simple requests stay concise, while rough or ambiguous requests receive grounded clarification.

### Higher-quality image prompts

- Added faithful, platform-specific prompt editing for Midjourney, DALL-E, Stable Diffusion, and generic image generators.
- Midjourney enhancements preserve user-supplied parameters and no longer invent aspect ratios, model versions, style modes, or stylize values.
- Image prompts preserve exact counts, ordering, colors, visible text, exclusions, composition, and supplied style constraints.
- Stable Diffusion negative prompts are tailored to the requested medium instead of using generic quality and anatomy boilerplate.
- Intentional unusual anatomy and construction are protected from contradictory negative prompts.
- Detailed image ideas receive light cleanup rather than an unrelated default aesthetic recipe.

### Prompt-quality evaluation

- Added versioned general-text and image-prompt evaluation corpora.
- Extended the evaluator to support text and image enhancement types, corpus-specific rubrics, and custom scoring dimensions.
- Blind evaluation showed the selected general-text strategy winning 10 of 12 comparisons and the selected image strategy winning 11 of 12, with no remaining candidate critical failures.

### macOS Accessibility and diagnostics

Selected-text capture/replacement on macOS requires Accessibility permission.

Proompt writes a local troubleshooting file at:

`~/Library/Application Support/proompt/selection-diagnostics.json`

This file contains only metadata such as capture status, sanitized error codes, input source, routing and delivery status, active app/window metadata, character counts, and replacement fallback reasons. It does **not** contain selected text, prompt content, enhanced output, clipboard content, or API keys. The file stays on your device and can be deleted anytime.

If an unsigned build appears enabled in Accessibility settings but stops capturing selections after an update/rebuild, reset permission and grant it again:

```bash
tccutil reset Accessibility com.proompt.desktop
open /Applications/Proompt.app
```

### Desktop release note

- Desktop DMG is macOS Apple Silicon only for now.
- Desktop app is unsigned and not notarized.
- Unsigned releases are expected while Developer ID signing is deferred.
- If macOS says the app is damaged, run:

```bash
xattr -dr com.apple.quarantine /Applications/Proompt.app
open /Applications/Proompt.app
```
