## What's Changed

### Quick Enhance self-check

- Settings now includes a one-click Quick Enhance self-check.
- The self-check reports macOS Accessibility trust, verifies text clipboard read/write and restoration, summarizes provider readiness, and previews clipboard routing.
- Clipboard verification restores the original text after the check and avoids replacing non-text clipboard contents when text cannot be read.

### End-to-end Quick Enhance diagnostics

- The last Quick Enhance attempt now records whether input came from selected text or the clipboard.
- Diagnostics show the resolved target, routing source, confidence, and reason.
- Diagnostics show whether Proompt replaced the selection or copied the result, including a safe fallback reason when replacement was not possible.
- Provider, network, and setup failures recorded after input capture are reduced to sanitized diagnostic codes instead of persisting raw provider responses.
- Existing diagnostics files remain compatible with the expanded schema.

### Reliability and QA

- Expanded the unsigned macOS QA runbook to cover the self-check, route, delivery, and privacy fields.
- Added regression coverage for diagnostics compatibility, stable serialization, and safe error classification.

### macOS Accessibility and diagnostics

Selected-text capture/replacement on macOS requires Accessibility permission.

Proompt writes a local troubleshooting file at:

`~/Library/Application Support/proompt/selection-diagnostics.json`

This file contains only metadata such as capture status, sanitized error codes, input source, routing and delivery status, active app/window metadata, character counts, and replacement fallback reasons. It does **not** contain selected text, prompt content, enhanced output, clipboard content, or API keys. The file stays on your device and can be deleted anytime.

If an unsigned build appears enabled in Accessibility settings but stops capturing selections after an update/rebuild, reset permission and grant it again:

```bash
tccutil reset Accessibility com.proompt.desktop
open /Applications/Proompt.app
```

### Desktop release note

- Desktop DMG is macOS Apple Silicon only for now.
- Desktop app is unsigned and not notarized.
- Unsigned releases are expected while Developer ID signing is deferred.
- If macOS says the app is damaged, run:

```bash
xattr -dr com.apple.quarantine /Applications/Proompt.app
open /Applications/Proompt.app
```
