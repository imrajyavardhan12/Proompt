## What's Changed

### Higher-quality coding-agent prompts

- Improved prompts for Claude Code, Cursor, Codex, and generic coding agents.
- Prompt enhancements now preserve uncertainty instead of presenting suspected causes as confirmed facts.
- Coding-agent prompts avoid inventing repository paths, symbols, frameworks, commands, domain rules, or test cases that were not provided by the user.
- Bug, feature, refactor, migration, investigation, and tests-only tasks now receive workflows appropriate to the task type.
- Simple tasks stay compact while ambiguous or risky work receives proportionate structure and verification guidance.
- Numeric boundaries are preserved and verified below, at, and above the supplied threshold when applicable.

### Focused desktop workspace

- Replaced the sidebar-heavy control panel with a focused prompt workspace.
- Added compact Quick Enhance readiness, provider, routing, and selected-text status.
- Recent prompt history is available directly from the workspace and can be reused with one click.
- Templates remain available without occupying permanent primary navigation.
- Settings now uses progressive disclosure, with diagnostics grouped behind a clear Troubleshoot entry.
- Refreshed the desktop interface with subtle Apple-inspired glass materials and a clearer Settings icon.

### Provider reliability

- OpenAI, OpenRouter, Anthropic, and Gemini requests now have a 60-second upper bound.
- Timeouts cover batch requests, streaming responses, response parsing, API error bodies, and connection tests.
- Manual and Quick Enhance flows now show actionable timeout guidance.
- Troubleshoot diagnostics record a safe timeout code without persisting raw provider responses.

### Prompt-quality evaluation

- Added a versioned coding-agent evaluation corpus and review rubric.
- Added local tooling for cost-confirmed capture and deterministic blind baseline-versus-candidate comparisons.
- Evaluation runs remain separate from the shipped CLI, normal prompt history, and SuperMemory.

### macOS Accessibility and diagnostics

Selected-text capture/replacement on macOS requires Accessibility permission.

Proompt writes a local troubleshooting file at:

`~/Library/Application Support/proompt/selection-diagnostics.json`

This file contains only metadata such as capture status, sanitized error codes, input source, routing and delivery status, active app/window metadata, character counts, and replacement fallback reasons. It does **not** contain selected text, prompt content, enhanced output, clipboard content, or API keys. The file stays on your device and can be deleted anytime.

If an unsigned build appears enabled in Accessibility settings but stops capturing selections after an update/rebuild, reset permission and grant it again:

```bash
tccutil reset Accessibility com.proompt.desktop
open /Applications/Proompt.app
```

### Desktop release note

- Desktop DMG is macOS Apple Silicon only for now.
- Desktop app is unsigned and not notarized.
- Unsigned releases are expected while Developer ID signing is deferred.
- If macOS says the app is damaged, run:

```bash
xattr -dr com.apple.quarantine /Applications/Proompt.app
open /Applications/Proompt.app
```
